- 原角色已调整后的关节坐标、骨骼滚转、面部贴合和装备活动空间。

本次扩写采用可执行的简化方案，不把单骨权重当柔性人体变形，不把正向运动学步行当精确锁脚系统。参考依据见[官方资料](REFERENCES.md)。
