# 环境与操作约定

## 基础设置

使用 Blender 4.5 LTS，编辑 → 偏好设置 → 界面 → 翻译，语言选择简体中文，并开启界面翻译。课程按默认 Blender 键位、鼠标左键选择编写；行业兼容键位可能不同。

场景属性 → 单位，单位制选择公制，单位缩放 1，长度按米显示。尺寸字段指包围尺寸 X×Y×Z，位置指物体原点位置，缩放指变换倍数，它们不是同一数据。先改变静态几何尺寸再应用缩放；绑定和动画后应用变换需独立评估。

三维坐标：X 左右、Y 前后、Z 高度，角色正面 -Y。底稿左侧零件位于 X<0，本教材沿用此名称，防止骨骼和部件配对错乱。不要把名称约定理解为所有角色的解剖左右标准。

## 操作速查

| 操作 | 默认快捷键/说明 |
|---|---|
| 添加 | Shift+A，菜单随当前模式变化 |
| 移动/旋转/缩放 | G/R/S，随后轴字母与数值，回车确认 |
| 物体/编辑模式 | Tab；骨架动画使用姿态模式 |
| 顶点/边/面选择 | 编辑模式主键盘 1/2/3 |
| 正视/右视/顶视 | 小键盘 1/3/7 |
| 摄像机视图 | 小键盘 0 |
| 聚焦所选 | 小键盘 .；无小键盘用视图菜单 |
| 透视模式 | Alt+Z，可选择背面元素，选择完及时关闭 |
| 比例编辑 | O，操作中滚轮调整影响范围 |
| 环切/倒角/内插/挤出 | Ctrl+R / Ctrl+B / I / E，先确认选择类型 |
| 选择关联元素/分离 | 编辑模式 L / P；L 不是“选择左边” |
| 复制 | Shift+D；Alt+D 为关联复制，共享网格 |
| 重命名/移动到集合 | F2 / M（物体模式） |
| 应用缩放 | 物体模式 Ctrl+A → 缩放 |
| 保存/另存为 | Ctrl+S / Ctrl+Shift+S |
| 渲染当前帧/动画 | F12 / Ctrl+F12 |

快捷键作用于鼠标所在编辑器，主键盘数字与小键盘不同。右键取消 E 的移动不会取消新产生的挤出拓扑；要完全撤销用 Ctrl+Z。F9 只能调整最近一次支持参数的操作，别在完成其他操作后再尝试修改旧几何体创建参数。

## 文件约定

每天另存 `DayNN_主题.blend`，应用修改器或绑定前加 `_source` 备份。图像绘制后另存 PNG；保存 .blend 不代表新画的外部图像已经保存。渲染图也需要图像 → 另存为。

教程中的 .blend、纹理与预览是学习者应生成的产物，不是仓库预附下载。无法完成前一课时可以用简单代理几何练习下一技能，但应记录替代内容。

## 中文术语

使用面光、棱角球、实体化、镜像、范围限制、合并间距、插帧集、原理化 BSDF、基础色等界面名。格式/引擎标识如 FBX、glTF、EEVEE，以及自定动作名 `Idle_01` 保留原样。追加文件内部的 `Collection` 等是数据目录标识，不是另行译写的菜单名称。
