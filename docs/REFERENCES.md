# 官方参考资料

核对日期：2026-11-18。教材以自主编写练习为主，以下资料用于核对功能语义与版本行为，不全文复制手册。Blender 手册部分译文仍含未翻译内容，菜单以 4.5 简体中文实际界面为准。

- [镜像修改器](https://docs.blender.org/manual/zh-hans/4.5/modeling/modifiers/generate/mirror.html)：镜像物体、范围限制、合并及距离。
- [集合](https://docs.blender.org/manual/zh-hans/4.5/scene_layout/collections/collections.html)：实例偏移与集合管理。
- [UV 操作](https://docs.blender.org/manual/zh-hans/4.5/modeling/meshes/editing/uv.html)：智能 UV 投射、边距与展开。
- [骨骼父级](https://docs.blender.org/manual/zh-hans/4.5/animation/armatures/bones/editing/parenting.html)：保持偏移与连接。
- [物体父级](https://docs.blender.org/manual/en/4.5/scene_layout/object/editing/parent.html)：骨骼父级与相关骨骼行为差别；英文参考页仅用于核对，不作为教程菜单译名。
- [编辑关键帧](https://docs.blender.org/manual/en/4.5/animation/keyframes/editing.html)：I、默认关键通道及活动插帧集。
- [插帧集](https://docs.blender.org/manual/zh-hans/4.5/animation/keyframes/keying_sets.html)：选择活动插帧集。
- [动作编辑器](https://docs.blender.org/manual/zh-hans/4.5/editors/dope_sheet/modes/action.html)：动作、槽与数据保留。
- [形态键简介](https://docs.blender.org/manual/zh-hans/4.5/animation/shape_keys/introduction.html)及[工作流程](https://docs.blender.org/manual/zh-hans/4.5/animation/shape_keys/workflow.html)：基型、相对形态与顶点变形。
- [FBX](https://docs.blender.org/manual/zh-hans/4.5/addons/import_export/scene_fbx.html)：导入导出选项与限制；该页面部分兼容性文字可能滞后，以实际导出器和回读实验为准。
- [glTF 2.0](https://docs.blender.org/manual/zh-hans/4.5/addons/import_export/scene_gltf2.html)：动画及材质交换参考。
- [虚幻引擎骨架网格体管道](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/fbx-skeletal-mesh-pipeline-in-unreal-engine)：目标引擎 FBX 骨架、蒙皮与版本要求。

引用页面和第三方软件遵循其自身许可。本教材许可证不覆盖上述外部网页与产品。
