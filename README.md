# Blender 30 天：从零基础到 Low Poly 游戏角色与场景

面向零基础学习者的简体中文教材：基础道具 → 村庄场景 → Q 版分体角色 → 骨架与动画 → 游戏资源准备。**基准：Blender 4.5 LTS 简体中文界面。**

## 这套教材来自哪里

- 第 1–12 天：底稿仅保留历史概要，本版补充完整操作与练习，**不是历史逐字复刻**。

教材已进行文档检查及部分 Blender 后台实验；没有宣称 30 天均已逐步界面实测或在虚幻引擎中验证。详见[来源与进度](docs/PROGRESS.md)、[验证记录](docs/VALIDATION.md)。本仓库交付 Markdown 教材，不包含未实际制作的 .blend、贴图或渲染示例。

## 如何学习

1. 先读[环境与操作约定](docs/SETUP.md)。建议每天 60–120 分钟，动画与导出课可拆成两次。
2. 按课前输入工程或前一天结果继续，每天另存文件，保留应用修改器前的源版本。
3. 每天完成操作、练习和验收，记录问题。遇到错误先看[常见问题](docs/FAQ.md)与[纠错说明](docs/CORRECTIONS.md)。
4. 所有示例数值是参考，不覆盖你已经调整好的角色；后续绑定必须根据实际关节位置检查。
5. 第 19–26 天采用分体刚性角色；第 27 天在副本中转换为游戏蒙皮数据。进阶连续网格与柔性权重不属于本课必达结果。
