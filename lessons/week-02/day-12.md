## 底稿知识与历史答疑（已作必要文字校正）

**原练习流程**：
1. 制作简单倒角木箱。
2. 编辑模式全选面，`U → 智能 UV 投射`。
3. 在 UV 编辑器新建约 1024×1024 的棕色图像「木箱贴图」。
4. 建立「木箱材质」，在着色工作区增加「图像纹理」节点，选择木箱贴图，将其「颜色」输出连接「原理化 BSDF」的「基础色」输入。
5. 在纹理绘制工作区绘制木纹。
6. 图像需要单独保存（图像 → 另存为），并保存 `.blend`；按需打包纹理。

**用户提问**：UV 投影看起来像多个面重叠堆在一起。

**答疑整理**：
- 在编辑模式确认已选中全部需要展开的面，再次执行 `U → 智能 UV 投射`，并尝试岛边距（例如 `0.03`）。
- 在 UV 编辑器中查看是否真正得到不重叠的 UV 岛，必要时 `Home` 查看全部区域。
- 如果已有绘制纹理，**重新展开会改变现有贴图对应关系**，先备份图像。
- 进阶可通过标记缝合边再使用「展开」，人工安排主要面和倒角条的位置。

**校对提示**：智能 UV 投射是否足以解决问题取决于具体网格、选择状态和当前 UV 层；不能仅凭截图断言所有 UV 面均重叠。

## 完整实操（本次扩写与纠错）

预计 90–120 分钟。另存 `Day12_Crate_UV.blend`，木箱尺寸设为 `(1,1,1)`，底部 Z=0。先应用缩放，再添加宽度 `0.02`、段数 1 的倒角；在展开前应用倒角，把实际需要贴图的窄面纳入 UV。

1. 物体数据属性中确认有一层 UV 贴图。编辑模式在三维视图 A 全选，U 选择「智能 UV 投射」，角度限制可从 `66°` 开始，边距先用 `0.03` 作为视觉测试值。参数含义随定距方法变化，不能无条件说它等于 30 像素。
2. 切到「UV 编辑」工作区。三维视图保持面全选，UV 编辑器 Home 查看全部。观察六个主要面和窄倒角条是否分开，不能用默认立方体已有 UV 的外观来判断新展开是否成功。
3. 在 UV 编辑器中选择一个岛，G 移动一点测试关联面；随后撤销。若所有主要面叠在同一方块，检查是否执行了「重置」而不是智能 UV 投射。
4. UV 编辑器「图像 → 新建」，名称「木箱贴图」，宽高 `1024`，填充棕色。材质中新建「图像纹理」节点，选择该图像，连接颜色输出到「原理化 BSDF → 基础色」。选择这个图像纹理节点作为绘制目标。
5. 切到「纹理绘制」工作区，先用明显红色画一个小点确认落到正确木箱面上；撤销测试。再用深棕色绘制竖向木纹，笔刷半径约 10–20 像素、强度约 0.3，分几次叠加。
6. 在每个面边缘画浅色细线模拟木板边沿；UV 岛之间留足空白，笔刷不要涂到邻岛。实际导出使用小尺寸纹理时仍需检查边缘渗色。
7. 「图像 → 另存为」保存 `textures/crate_basecolor.png`，再保存 .blend。可通过「文件 → 外部数据 → 打包资源」做便携备份，但保留外部 PNG 方便游戏导入。
8. 关闭再打开工程，切材质预览核对图像是否仍在。保存工程并不自动等于保存了所有尚未落盘的绘制图像。

### 手工缝合边补充练习

在无倒角立方体副本上，边选择，选顶面四边、底面四边，以及一条竖边；Ctrl+E 选择「标记缝合边」。全选面后 U → 展开，得到上下两面及侧面条带。用方格测试图观察是否拉伸。此步骤只在副本练习，不破坏已画木纹的 UV。

## 常见问题与练习

- 画笔无反应：确认模式、活动图像、材质节点和 UV 层；先用大笔刷纯色测试，再调整细节。
- 重新展开后木纹乱了：UV 与图像是映射关系，先恢复旧 UV 或回到备份；不能指望绘制自动重排。
- 练习：做一面带编号的木箱，检验是否意外出现在其他面上；比较 1024 和 256 像素下的接缝。
- 验收：六个主要面无非预期重叠、木纹可辨、外部 PNG 存在且重开工程不丢图。
