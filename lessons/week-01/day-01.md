## 底稿知识与历史答疑（已作必要文字校正）

**课程内容**：通过立方体、柱体、球体组合机器人头部、身体、四肢；认识物体模式、编辑模式、移动、旋转、缩放以及物体原点。

**主要知识**：
- `Shift + A` 添加网格几何体；`G` 移动、`R` 旋转、`S` 缩放。
- 几何体相交并不自动焊接为一个连续网格，后续动画需考虑组件结构。
- 物体原点的位置影响旋转和装配。

**答疑要点**：讨论过避免不自然的模型穿插、精确定位与原点的重要性。

## 跟做步骤（本次扩写）

预计 60–90 分钟。新建常规工程，先保存 `Day01_Robot.blend`。本课采用米制、单位缩放 1，X 为左右、Y 负方向为正面、Z 向上。快捷键作用于鼠标所在编辑器，输入数字后按回车确认。

1. 选中默认立方体，`F2` 命名「机器人_身体」。按 `N` 打开侧栏，在「条目 → 变换」中填写下表尺寸和位置。尺寸是完整边长，不是缩放倍数。
2. 物体模式 `Ctrl + A → 缩放`。几何外观保持不变，缩放变成 1；这一步让后续倒角宽度一致。
3. `Shift + A → 网格 → 立方体` 添加头部。每添加一个物体立即命名、设置尺寸和位置，再应用缩放。
4. 制作左臂后 `Shift + D`，按 `X` 输入 `1.3`，得到右臂。复制左腿时沿 X 输入 `0.6`。注意复制产生的是另一个物体。
5. 为双眼添加小立方体。双眼位于头部前表面之外，先从正视图检查，再从侧视图排除埋入头内的问题。
6. 鼠标中键环绕，滚轮缩放，`Shift + 鼠标中键` 平移；数字小键盘 `1/3/7` 查看正面、右侧、顶面，小键盘 `.` 聚焦所选。没有小键盘时用「视图 → 视角」及「视图 → 框选所选」。
7. 选择全部机器人零件，`M → 新建集合`，命名「机器人」。保存；本日不要求灯光和渲染。

| 零件 | 尺寸 X×Y×Z | 位置 X,Y,Z |
|---|---|---|
| 身体 | 1×0.6×1 | 0,0,1.3 |
| 头 | 0.8×0.65×0.65 | 0,0,2.125 |
| 左臂 | 0.25×0.35×0.85 | -0.65,0,1.3 |
| 左腿 | 0.3×0.4×0.8 | -0.3,0,0.4 |
| 左眼 | 0.14×0.06×0.14 | -0.2,-0.35,2.17 |
| 右眼 | 同左眼 | 0.2,-0.35,2.17 |

这些尺寸为本次新增练习值，不代表历史原始尺寸。独立零件适度相交可避免缝隙，但不能把穿插误认为焊接。`Ctrl + J` 合并物体也不会自动焊接交叉的面。

## 常见问题与练习

- 一次缩放了多个零件：先 `Alt + A` 取消选择，再单选目标；确认在物体模式。
- 看起来只剩一条线：切换视角；检查是否误把某轴缩放成 0。
- 练习：把头改成棱角球并调整到相同包围尺寸；将左右手改成不同工具，仍保持站立平衡。
- 验收：所有物体有名称、脚底在 Z=0、双眼朝 -Y；提交正面和三分之四视角截图以及工程文件。
