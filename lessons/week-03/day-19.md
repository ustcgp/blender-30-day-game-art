## 底稿知识与历史答疑（已作必要文字校正）

**目标**：添加骨架、建立根部到头部、左右手臂和腿部的骨骼层级，将独立网格刚性绑定至对应骨骼。

**工程**：Day 18 另存 `Day19_Character_Rig.blend`。

### 创建骨架和显示

1. 物体模式按 `Shift + A → 骨架`。在用户 Blender 中文版本中，此处菜单项**只有「骨架」**，并不存在此前教程写的「骨架 → 单段骨骼」。添加骨架后自带一根骨骼。
2. 选骨架后在**物体属性**（橙色方块）→ **视图显示** 勾选 **在前面**，让骨骼能够透过角色显示；不要与**骨架数据属性**（绿色骨架图标）的「视图显示」混淆。
3. `Tab` 进入骨架编辑模式，选中骨骼 `F2` 命名。
4. 默认八面体显示下，**粗端为头部，尖端为尾部**（其他显示类型请检查头尾坐标）。选中尖端后按 `E` 挤出下一根骨骼。

### 主要骨骼参考坐标

| 骨骼 | 头部坐标 | 尾部坐标 |
|---|---|---|
| 根部 | `(0,0,0.15)` | `(0,0,0.90)` |
| 躯干 | `(0,0,0.90)` | `(0,0,1.75)` |
| 颈部 | `(0,0,1.75)` | `(0,0,1.90)` |
| 头部 | `(0,0,1.90)` | `(0,0,2.75)` |
| 左大臂 | `(-0.62,0,1.76)` | `(-0.62,0,1.34)` |
| 左小臂 | `(-0.62,0,1.34)` | `(-0.62,0,0.94)` |
| 左大腿 | `(-0.25,0,0.90)` | `(-0.25,0,0.51)` |
| 左小腿 | `(-0.25,0,0.51)` | `(-0.25,0,0.13)` |

右侧肢体参考左侧坐标镜像，X 号改为正数；根据实际角色调整。

**挤出操作示例**：
- 根部尾端 `E → Z → 0.85` → 躯干。
- 躯干尾端 `E → Z → 0.15` → 颈部。
- 颈部尾端 `E → Z → 0.85` → 头部。
- 左大臂尾端 `E → Z → -0.4` → 左小臂。
- 左大腿尾端 `E → Z → -0.38` → 左小腿（从 Z=0.51 到 Z=0.13）。

### 骨骼的层级与绑定

- 「根部 → 躯干 → 颈部 → 头部」可通过连续挤出形成父子层级。
- 独立建立的大臂骨骼应成为躯干的子骨骼；大腿应成为根部的子骨骼。编辑模式中先选子骨骼，再将父骨骼设为活动项，`Ctrl + P → 保持偏移`，避免强制改变骨骼关节位置。
- 本阶段使用的是**骨骼父级绑定**（刚性），适用于独立物体。选网格后选骨架，切换姿态模式、选中指定骨骼，再 `Ctrl + P → 骨骼`。需对头部、五官、头发、躯干、大臂、小臂、腿部和装备分别指定骨骼。
- 初始测试：姿态模式选中骨骼，`R` 轻微旋转；子骨骼应该跟随，正确绑定的网格物体也应随之移动。`Alt + R` 还原测试旋转。

### Day 19 答疑 1：根部到头部的层级是否正确？

用户截图的大纲视图显示：`根部 → 躯干 → 颈部 → 头部`，层级正确。大纲视图**不能仅凭层级确认骨骼的实际空间位置**；还应在三维视图检查是否对准身体、脖子和头部。

### Day 19 答疑 2：左小腿挤出长度

用户问左小腿需要多长：答复为 `0.38 m`，向 Z 轴负方向挤出：`E → Z → -0.38 → Enter`。左小腿头部 `(-0.25,0,0.51)`，尾部 `(-0.25,0,0.13)`。

### Day 19 答疑 3：镜像出来的左右手臂会一起被绑定吗？

**用户观察**：选择一边大臂时，另一边也自动选中。

**回答**：如果左右两侧来自**同一个带镜像修改器的物体**，那么直接把整个物体作为某一根骨骼的子物体，左右两侧会一起随这根骨骼移动。因此在当前**刚性骨骼父级绑定**方案中，应先将左右网格分离为独立物体。

**处理步骤**：
1. 保存工程副本。
2. 物体模式选中肢体，进入**修改器属性 → 镜像**，在修改器菜单中**应用**。
3. `Tab` 进入编辑模式，按 `Alt + A` 取消全选。
4. 鼠标悬停在其中一侧网格上，按 `L` **选择关联元素**（前提是两侧没有被连接成一体）。
5. 按 `P → 选中项`，分离成新物体。
6. 返回物体模式，分别命名左右大臂并确认可单独选取。
7. 小臂、手掌、腿和装备按需重复，分别绑定到左右对应骨骼。

**快捷键解释**：
- `L`：**选择关联元素**，选中鼠标下方相互连通的网格，不是“选左侧”。
- `P`：**分离**，把被选中网格拆成独立物体。

**进阶区别**：连续网格人物可以借助**骨架修改器、顶点组和权重绘制**让同一物体左右两部分接受不同骨骼控制；不必在所有角色工程中都应用镜像、分离两边。本课程采用简化法是为了适配当前分体模型。

### Day 19 答疑 4：骨骼父级关系会在大纲视图体现吗？

答复：**会体现一部分**。网格通常显示在骨架物体的父子层级下，但不一定直接按指定骨骼名称嵌套；仅凭缩进不能判断具体绑定对象。

准确检查：选择网格物体，打开 **物体属性 → 关系**，查看：
- 父级是否为「角色骨架」。
- 父级类型是否为「骨骼」。
- 父级骨骼是否为对应骨骼（如「左大臂」）。

再通过姿态模式轻微旋转对应骨骼做验证。

## 从骨架到逐件绑定（本次扩写与纠错）

预计 120 分钟。先保存未绑定副本。为后续导出准备，网格和骨架应在绑定前处理好尺寸、旋转和缩放，之后不要随意应用骨架变换。

1. 添加骨架后进入编辑模式，选中默认整根骨骼，在侧栏把头部设 `(0,0,0.15)`、尾部设 `(0,0,0.9)`，命名「根部」。不先调整默认骨骼就挤出，会使后面的所有高度错位。
2. 仅选根部尾端，E Z 0.85 得到躯干，再依底稿挤出颈部和头部。每次 F2 命名，确认当前选中的是新骨骼。
3. 编辑模式添加独立骨骼，分别设置左大臂头尾坐标；选尾端挤出左小臂。右侧可独立创建并输入正 X 坐标，本课程暂不依赖自动对称命名。
4. 创建左右大腿、小腿。先选大臂，再 Shift 选躯干为活动骨骼，Ctrl+P → 保持偏移；大腿同样挂到根部。连接的小臂和小腿继承各自上段，检查没有错挂到对侧。
5. 先绑定一个左大臂作为测试：物体模式只选左大臂网格，再 Shift 选骨架，使骨架活动；通过模式菜单进入「姿态模式」，选中左大臂骨骼；Ctrl+P → 骨骼。执行后检查网格物体属性的「关系」，确认父级类型和父级骨骼。
6. 若模式切换导致无法同时选网格，可在姿态模式先激活目标骨骼，再在大纲视图辅助选择网格与骨架；关键是执行父级命令时网格为子物体、骨架为活动物体且目标骨骼活动。不要只给骨架物体做普通父级。
7. 姿态模式 R Y 15 测试：只左大臂及其后续子链应移动；Alt+R 恢复。按下表逐项绑定，每完成一组就测试，避免全部完成后找漏项。

| 网格部件 | 目标骨骼 |
|---|---|
| 身体、腰带、腰包及其配件 | 躯干 |
| 颈部网格 | 颈部 |
| 头、眼、鼻、嘴、耳、发帽、刘海 | 头部 |
| 左/右大臂、肩甲 | 同侧大臂 |
| 左/右肘、小臂、手、护腕 | 同侧小臂 |
| 左/右大腿 | 同侧大腿 |
| 左/右膝、小腿、鞋 | 同侧小腿 |

肘球和膝球被指定到下段，是本课程的刚性关节设计；它们不会产生软组织变形。可按造型调整，但须记录规则。

## 常见问题与练习

- 绑定时跳位：撤销，检查是否选错父级类型、是否已有旧父级，以及是否在非中立姿态操作。不能靠移动网格硬补回去。
- 两只手一起动：按底稿应用镜像并分离左右；若两边本身连通，L 会选中整个网格，应按几何位置手工选择，而不是反复按 L。
- 骨骼粗端/尖端判断仅适用于默认八面体显示；其他显示类型用骨骼数据的头部、尾部坐标确认。
- 练习：分别旋转四个大关节 15°，旋转头部 20°，每次检查装备后复位；根部平移 0.2 m 时全部角色应跟随。
- 验收：逐件绑定表无漏项，左右独立，姿态模式变动有效，编辑模式下不拿静止骨骼位置当动画姿势修改。
